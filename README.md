상황: 최근 전기차 시장의 급진적인 성장으로 인하여 전기차 배터리 화재 또한 사회적 이슈로 떠오르고 있다. 전기차 배터리 화재는 또 다른 이름으로 배터리 열폭주 화재라는 이름을 가지고 있는데, 전기적 화재이자 폭발성을 가진 화재로 분류되어 피해가 매우 크며 소방기관의 특수 장비와 초동 대응없이는 화재의 진압이 사실상 매우 힘들다.

대응 제품: 배터리 상부에 열변색 패치를 부착하여 배터리 열폭주를 조기에 감지하고 이를 운전자와 소방 기관에 연락하여 초동 대응을 신속하게 진행할 수 있게 하는 배터리 열폭주 조기 감지 시스템이다.
